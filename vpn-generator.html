Usage notes

  • client.ovpn — the main profile. It already embeds the CA certificate, the client certificate and the client private key, so it can be imported into any OpenVPN client as-is.
  • ca.crt — the certificate-authority certificate. Install it on the server (and keep it for trust / future re-issuing).
  • client.crt + client.key — the client credentials (same material that is embedded in the .ovpn file, provided separately in case your client wants them split out).
  • server.crt + server.key — paste these into the OpenVPN server config with cert and key directives.
  • All RSA-2048 keys and X.509 v3 certificates are generated locally. Nothing is uploaded anywhere.
  • The tool uses the Web Crypto API (crypto.subtle), which requires a secure context: HTTPS or localhost.
